## Antigravity & ECC Architecture

This repository is configured with the ECC Universal developer suite for Antigravity:
- **Rules (`.agents/rules/`)**: Coding standards, performance, security, and TypeScript guidelines.
- **Specialized Agents (`.agents/agents/`)**: Subagent definitions for review and development (e.g., `react-reviewer`, `typescript-reviewer`, `a11y-architect`, `code-reviewer`, `performance-optimizer`).
- **Skills (`.agents/skills/`)**: On-demand runbooks for testing, refactoring, quality audits, and UI animation.
- **Workflows (`.agents/workflows/`)**: Standardized procedures for planning, feature development, and quality gates.
